Экспериментальная задача

5 баллов на экзаменеСкладывается из двух критериев: уравнения реакций — до 2 баллов, оформление результатов опытов — до 3 баллов.

★ Задание повышенной сложности. Соль аммония выдаёт себя запахом, а не осадком: это единственный в задании признак, который распознают не глазами. Влажная лакмусовая бумажка над пробиркой синеет.

Для ответа на задание 23 используйте БЛАНК ОТВЕТОВ № 2. Запишите сначала номер задания (23), а затем развёрнутый ответ к нему. Ответ записывайте чётко и разборчиво. Для оформления ответа используйте предложенную в задании табличную форму, которую следует перенести в БЛАНК ОТВЕТОВ № 2.

Для проведения эксперимента выданы склянки № 1 и № 2 с растворами сульфата аммония и хлорида бария, а также три реактива: соляная кислота, растворы гидроксида калия и фосфата натрия (возможно использование лакмусовой бумаги).

  1. только из указанных в перечне трёх реактивов выберите два, которые необходимы для определения каждого вещества, находящегося в склянках № 1 и № 2;
  2. составьте молекулярное, полное и сокращённое ионное уравнения реакции, которую планируете провести для определения вещества из склянки № 1;
  3. составьте молекулярное, полное и сокращённое ионное уравнения реакции, которую планируете провести для определения вещества из склянки № 2;
  4. для оформления хода эксперимента используйте предложенную ниже таблицу;
  5. приступайте к выполнению эксперимента.

Ход решения

Выбранные реактивы: раствор гидроксида калия KOH и раствор фосфата натрия Na3PO4. Соляная кислота не годится: ни с сульфатом аммония, ни с хлоридом бария она не реагирует.

Опыт 1 — гидроксид калия (определяем сульфат аммония):

(NH4)2SO4 + 2KOH = K2SO4 + 2NH3↑ + 2H2O
2NH4+ + SO42− + 2K+ + 2OH− = 2K+ + SO42− + 2NH3↑ + 2H2O
NH4+ + OH− = NH3↑ + H2O

Опыт 2 — фосфат натрия (определяем хлорид бария):

3BaCl2 + 2Na3PO4 = Ba3(PO4)2↓ + 6NaCl
3Ba2+ + 6Cl− + 6Na+ + 2PO43− = Ba3(PO4)2↓ + 6Na+ + 6Cl−
3Ba2+ + 2PO43− = Ba3(PO4)2↓

Наблюдения:

  • Опыт 1, KOH: из одной склянки при нагревании пошёл газ с резким запахом — влажная лакмусовая бумажка синеет; в другой изменений нет.
  • Опыт 2, Na3PO4: во второй склянке выпал белый осадок.
  • ВЫВОД: склянка, из которой пошёл аммиак, содержит сульфат аммония (NH4)2SO4; вторая — хлорид бария BaCl2.
