★Задание 23 № 1870

Экспериментальная задача

5 баллов на экзаменеСкладывается из двух критериев: уравнения реакций — до 2 баллов, оформление результатов опытов — до 3 баллов.

★ Задание повышенной сложности. Оба признака нетипичны: первый — не обмен, а вытеснение металла (медь левее серебра в ряду активности); второй — осадок малорастворимого сульфата кальция, который в таблице растворимости стоит с пометкой «М».

Для ответа на задание 23 используйте БЛАНК ОТВЕТОВ № 2. Запишите сначала номер задания (23), а затем развёрнутый ответ к нему. Ответ записывайте чётко и разборчиво. Для оформления ответа используйте предложенную в задании табличную форму, которую следует перенести в БЛАНК ОТВЕТОВ № 2.

Для проведения эксперимента выданы склянки № 1 и № 2 с растворами нитрата серебра и серной кислоты, а также три реактива: медь, оксид кремния(IV) и раствор нитрата кальция.

  1. только из указанных в перечне трёх реактивов выберите два, которые необходимы для определения каждого вещества, находящегося в склянках № 1 и № 2;
  2. составьте молекулярное, полное и сокращённое ионное уравнения реакции, которую планируете провести для определения вещества из склянки № 1;
  3. составьте молекулярное, полное и сокращённое ионное уравнения реакции, которую планируете провести для определения вещества из склянки № 2;
  4. для оформления хода эксперимента используйте предложенную ниже таблицу;
  5. приступайте к выполнению эксперимента.

ВЫВОД:

Выбирайте реактив, который даёт заметный и РАЗНЫЙ признак реакции (осадок, газ, изменение цвета) с одним веществом и не реагирует — или реагирует иначе — с другим, как в задании 17. В ионных уравнениях оставляйте в виде ионов только сильные растворимые электролиты (соли, сильные кислоты, щёлочи), а осадки, газы и слабые электролиты записывайте целыми формулами.

Ход решения

Выбранные реактивы: медь Cu и раствор нитрата кальция Ca(NO3)2. Оксид кремния(IV) не годится: он не растворяется ни в разбавленной серной кислоте, ни в растворе соли.

Опыт 1 — медь (определяем нитрат серебра):

Cu + 2AgNO3 = Cu(NO3)2 + 2Ag↓
Cu0 + 2Ag+ + 2NO3− = Cu2+ + 2NO3− + 2Ag↓
Cu0 + 2Ag+ = Cu2+ + 2Ag↓

Опыт 2 — нитрат кальция (определяем серную кислоту):

Ca(NO3)2 + H2SO4 = CaSO4↓ + 2HNO3
Ca2+ + 2NO3− + 2H+ + SO42− = CaSO4↓ + 2H+ + 2NO3−
Ca2+ + SO42− = CaSO4↓

Наблюдения:

  • Опыт 1, Cu: в одной склянке медь покрылась серым налётом, а раствор стал голубым; в другой изменений нет.
  • Опыт 2, Ca(NO3)2: во второй склянке выпал белый осадок.
  • ВЫВОД: склянка, в которой медь покрылась серебром, содержит нитрат серебра AgNO3; вторая — серную кислоту H2SO4.
