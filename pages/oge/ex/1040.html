Задание 17 № 1040

Качественные реакции неорганических соединений. Индикаторы

2 балла на экзаменеПолный правильный ответ — 2 балла; одна ошибка — 1 балл; две ошибки и более — 0.

Установите соответствие между двумя веществами, взятыми в виде водных растворов, и реактивом, с помощью которого можно различить эти вещества: к каждой позиции, обозначенной буквой, подберите соответствующую позицию, обозначенную цифрой.

Вещества
  • А) H2SO4 и HCl
  • Б) NaBr и NaOH
  • В) Al2(SO4)3 и MgSO4
Реактив
  • 1) фенолфталеин
  • 2) Ba(OH)2
  • 3) CO2
  • 4) KOH

Запишите в таблицу выбранные цифры под соответствующими буквами.

А Б В

Ищи реактив с РАЗНЫМ откликом на оба в-ва (осадок/нет, разный цвет, газ/нет).
Cl⁻/Br⁻/I⁻ → AgNO₃ (разные цвета, AgF растворим!). SO₄²⁻ → BaCl₂ (белый). CO₃²⁻/HCO₃⁻ → к-та (газ). Щёлочь: соли акт. Ме — без осадка, остальные — осадок.

Полный разбор всех проб

А) H2SO4 и HCl. Различает Ba(OH)2.

  • С фенолфталеином оба кислых раствора остаются бесцветными.
  • H2SO4 + Ba(OH)2 → BaSO4↓ + 2H2O (белый осадок).
  • 2HCl + Ba(OH)2 → BaCl2 + 2H2O (без индикатора видимого признака нет).
  • С CO2 у обоих растворов видимой реакции нет.
  • H2SO4 + 2KOH → K2SO4 + 2H2O.
  • HCl + KOH → KCl + H2O.
  • В нейтрализации с KOH без индикатора видимого признака нет.

Б) NaBr и NaOH. Различает фенолфталеин.

  • NaBr + фенолфталеин: раствор бесцветный.
  • NaOH + фенолфталеин: раствор становится малиновым.
  • С Ba(OH)2 у NaBr и NaOH видимой реакции нет.
  • CO2 + 2NaOH → Na2CO3 + H2O (видимого признака нет).
  • NaBr + CO2 — реакции нет.
  • С KOH у NaBr и NaOH видимой реакции нет.

В) Al2(SO4)3 и MgSO4. Различает KOH.

  • С фенолфталеином оба раствора бесцветные.
  • Al2(SO4)3 + 3Ba(OH)2 → 2Al(OH)3↓ + 3BaSO4↓ (белые осадки).
  • MgSO4 + Ba(OH)2 → Mg(OH)2↓ + BaSO4↓ (белые осадки).
  • С CO2 у обоих растворов видимой реакции нет.
  • Al2(SO4)3 + 6KOH → 2Al(OH)3↓ + 3K2SO4 (белый студенистый осадок).
  • Al(OH)3 + KOH(изб.) → K[Al(OH)4] (осадок растворяется, раствор бесцветный).
  • MgSO4 + 2KOH → Mg(OH)2↓ + K2SO4 (белый осадок, в избытке KOH не растворяется).
