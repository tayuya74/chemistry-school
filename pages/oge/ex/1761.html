Задание 18 № 1761

Вычисление массовой доли химического элемента в веществе

1 балл на экзамене

При проведении расчётов для всех элементов, кроме хлора, используйте целые значения относительных атомных масс (Ar(Cl) = 35,5).

Стекло — один из самых древних материалов. Тугоплавкое стекло получают плавлением смеси, в которой вместо соды используется поташ. В результате получается соединение оксидов K2O·CaO·6SiO2, молекулярную формулу которого можно представить брутто-формулой K2CaSi6O14.

Вычислите в процентах массовую долю кальция в стекле указанного состава. Запишите число с точностью до сотых.

Ответ (%):

Ход решения

M(K2CaSi6O14) = 78 + 40 + 168 + 224 = 510 г/моль.

w(Ca) = 40 / 510 · 100 % = 7,843… % ≈ 7,84 %.
