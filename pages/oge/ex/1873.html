Экспериментальная задача

★ Задание повышенной сложности. Выданные вещества реагируют друг с другом, но проверять их друг другом нельзя: по условию берут только реактивы из перечня.

ВЫВОД:

Выбирайте реактив, который даёт заметный и РАЗНЫЙ признак реакции (осадок, газ, изменение цвета) с одним веществом и не реагирует — или реагирует иначе — с другим, как в задании 17. В ионных уравнениях оставляйте в виде ионов только сильные растворимые электролиты (соли, сильные кислоты, щёлочи), а осадки, газы и слабые электролиты записывайте целыми формулами.

Ход решения

Выбранные реактивы: раствор гидроксида кальция Ca(OH)2 и раствор хлорида меди(II) CuCl2. Фосфат натрия не годится: с гидроксидом калия он не реагирует, а с хлоридом аммония видимых изменений не даёт.

Опыт 1 — гидроксид кальция (определяем хлорид аммония):

Ca(OH)2 + 2NH4Cl = CaCl2 + 2NH3↑ + 2H2O
Ca2+ + 2OH− + 2NH4+ + 2Cl− = Ca2+ + 2Cl− + 2NH3↑ + 2H2O
NH4+ + OH− = NH3↑ + H2O

Опыт 2 — хлорид меди(II) (определяем гидроксид калия):

CuCl2 + 2KOH = Cu(OH)2↓ + 2KCl
Cu2+ + 2Cl− + 2K+ + 2OH− = Cu(OH)2↓ + 2K+ + 2Cl−
Cu2+ + 2OH− = Cu(OH)2↓

Наблюдения:

  • Опыт 1, Ca(OH)2: из одной склянки при нагревании пошёл газ с резким запахом, в другой изменений нет.
  • Опыт 2, CuCl2: во второй склянке выпал голубой студенистый осадок.
  • ВЫВОД: склянка, из которой пошёл аммиак, содержит хлорид аммония NH4Cl; вторая — гидроксид калия KOH.
