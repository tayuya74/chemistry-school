Экспериментальная задача

5 баллов на экзаменеСкладывается из двух критериев: уравнения реакций — до 2 баллов, оформление результатов опытов — до 3 баллов.

★ Задание повышенной сложности. Оба осадка белые, поэтому различает не цвет, а реактив: соляная кислота действует только на серебро, нитрат бария — только на фосфат. Осаждать фосфат-ион нитратом серебра здесь нельзя — серебро само сидит в склянке.

Для ответа на задание 23 используйте БЛАНК ОТВЕТОВ № 2. Запишите сначала номер задания (23), а затем развёрнутый ответ к нему. Ответ записывайте чётко и разборчиво. Для оформления ответа используйте предложенную в задании табличную форму, которую следует перенести в БЛАНК ОТВЕТОВ № 2.

Для проведения эксперимента выданы склянки № 1 и № 2 с растворами нитрата серебра и фосфата калия, а также три реактива: соляная кислота, растворы нитрата калия и нитрата бария.

  1. только из указанных в перечне трёх реактивов выберите два, которые необходимы для определения каждого вещества, находящегося в склянках № 1 и № 2;
  2. составьте молекулярное, полное и сокращённое ионное уравнения реакции, которую планируете провести для определения вещества из склянки № 1;
  3. составьте молекулярное, полное и сокращённое ионное уравнения реакции, которую планируете провести для определения вещества из склянки № 2;
  4. для оформления хода эксперимента используйте предложенную ниже таблицу;
  5. приступайте к выполнению эксперимента.

Ход решения

Выбранные реактивы: соляная кислота HCl и раствор нитрата бария Ba(NO3)2. Нитрат калия не годится: он не реагирует ни с нитратом серебра, ни с фосфатом калия.

Опыт 1 — соляная кислота (определяем нитрат серебра):

AgNO3 + HCl = AgCl↓ + HNO3
Ag+ + NO3− + H+ + Cl− = AgCl↓ + H+ + NO3−
Ag+ + Cl− = AgCl↓

Опыт 2 — нитрат бария (определяем фосфат калия):

3Ba(NO3)2 + 2K3PO4 = Ba3(PO4)2↓ + 6KNO3
3Ba2+ + 6NO3− + 6K+ + 2PO43− = Ba3(PO4)2↓ + 6K+ + 6NO3−
3Ba2+ + 2PO43− = Ba3(PO4)2↓

Наблюдения:

  • Опыт 1, HCl: в одной склянке выпал белый творожистый осадок, в другой изменений нет.
  • Опыт 2, Ba(NO3)2: во второй склянке выпал белый осадок.
  • ВЫВОД: склянка, давшая творожистый осадок с соляной кислотой, содержит нитрат серебра AgNO3; вторая — фосфат калия K3PO4.
