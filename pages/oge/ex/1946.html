Задание 21 № 1946

Химические свойства простых и сложных веществ

3 балла на экзамене

Дана схема превращений:

Li2O → X → LiCl → LiNO3

Напишите молекулярные уравнения реакций, с помощью которых можно осуществить указанные превращения.

Вспомните взаимодействие оксида щелочного металла с водой. Для замены аниона в соли выберите реагент, с которым один из продуктов выпадает в осадок.

Ход решения

X — LiOH.

Li2O + H2O → 2LiOH

LiOH + HCl → LiCl + H2O

LiCl + AgNO3 → LiNO3 + AgCl↓
