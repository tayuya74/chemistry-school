Задание 23 № 1948

Экспериментальная задача (демоверсия ОГЭ 2027)

5 баллов на экзаменеСкладывается из двух критериев: уравнения реакций — до 2 баллов, оформление результатов опытов — до 3 баллов.

Для проведения эксперимента выданы склянки № 1 и № 2 с растворами гидроксида калия и сульфата натрия, а также растворы трёх реактивов: хлорида бария, пероксида водорода и сульфата железа(II).

  1. Только из указанных в перечне трёх реактивов выберите два, которые необходимы для определения каждого вещества, находящегося в склянках № 1 и № 2.
  2. Составьте молекулярное, полное и сокращённое ионные уравнения реакции, которую планируете провести для определения вещества из склянки № 1.
  3. Составьте молекулярное, полное и сокращённое ионные уравнения реакции, которую планируете провести для определения вещества из склянки № 2.
  4. Для оформления хода эксперимента используйте таблицу для записи результатов эксперимента.

5) Приступайте к выполнению эксперимента (на экзамене — по инструкции организаторов; не ранее чем через 30 минут после начала экзамена).

ВЫВОД:

Выберите реакции с различимым осадком для каждого раствора. В ионных уравнениях расписывайте сильные растворимые электролиты, а осадок оставляйте целой формулой.

Ход решения

По эталону: в склянке № 1 — KOH, в склянке № 2 — Na2SO4. Реактивы — FeSO4 и BaCl2.

Опыт 1:
2KOH + FeSO4 → Fe(OH)2↓ + K2SO4
2K+ + 2OH− + Fe2+ + SO42− → Fe(OH)2↓ + 2K+ + SO42−
Fe2+ + 2OH− → Fe(OH)2↓

Опыт 2:
Na2SO4 + BaCl2 → BaSO4↓ + 2NaCl
2Na+ + SO42− + Ba2+ + 2Cl− → BaSO4↓ + 2Na+ + 2Cl−
SO42− + Ba2+ → BaSO4↓
