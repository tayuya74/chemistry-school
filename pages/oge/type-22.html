Задание 22 № 1022

При проведении расчётов для всех элементов, кроме хлора, используйте целые значения Ar; Ar(Cl) = 35,5.

К 340 г раствора с массовой долей нитрата серебра 6 % добавили избыток раствора хлорида железа(III). Вычислите массу образовавшегося осадка.

В ответе запишите уравнение реакции, о которой идёт речь в условии задачи, и приведите все необходимые вычисления (указывайте единицы измерения искомых физических величин).

Общий план: 1) по массе, объёму или массовой доле раствора найдите массу или количество вещества исходного реагента (m(в-ва в растворе) = m(раствора) × w); 2) переведите в моли через Mr; 3) по уравнению реакции и его коэффициентам найдите количество вещества искомого продукта; 4) переведите в нужные единицы — массу через Mr, объём газа при н.у. через Vm = 22,4 л/моль. Проверьте, не дан ли один из реагентов в избытке.

Эталон ответа (демоверсия ОГЭ 2026)

Уравнение:

3AgNO3 + FeCl3 = 3AgCl↓ + Fe(NO3)3

Вычисления:

  • m(AgNO3) = m(р-ра) · ω / 100 = 340 · 0,06 = 20,4 г
  • n(AgNO3) = m / M = 20,4 / 170 = 0,12 моль
  • по уравнению n(AgCl) = n(AgNO3) = 0,12 моль
  • m(AgCl) = n · M = 0,12 · 143,5 = 17,22 г ≈ 17,2 г (в бланке — по правилам округления КИМ)

В официальном ключе демоверсии приведена масса AgCl = 17,22 г; при сдаче ориентируйтесь на требования бланка.

Задание 22 № 1045

При проведении расчётов для всех элементов, кроме хлора, используйте целые значения Ar; Ar(Cl) = 35,5.

Рассчитайте объём (н. у.) углекислого газа, который выделится при действии избытка карбоната магния на 97,33 г 15 % раствора соляной кислоты.

В ответе запишите уравнение реакции, о которой идёт речь в условии задачи, и приведите все необходимые вычисления (указывайте единицы измерения искомых физических величин).

Общий план: 1) по массе, объёму или массовой доле раствора найдите массу или количество вещества исходного реагента (m(в-ва в растворе) = m(раствора) × w); 2) переведите в моли через Mr; 3) по уравнению реакции и его коэффициентам найдите количество вещества искомого продукта; 4) переведите в нужные единицы — массу через Mr, объём газа при н.у. через Vm = 22,4 л/моль. Проверьте, не дан ли один из реагентов в избытке.

Ход решения

Уравнение:

MgCO3 + 2HCl = MgCl2 + H2O + CO2↑

Вычисления:

  • m(HCl) = m(р-ра) · ω / 100 % = 97,33 · 15 / 100 = 14,6 г
  • n(HCl) = m / M = 14,6 / 36,5 = 0,4 моль
  • по уравнению n(CO2) = ½ n(HCl) = 0,2 моль
  • V(CO2) = n · Vm = 0,2 · 22,4 = 4,48 л (н. у.)

Через раствор нитрата меди(II) массой 37,6 г с массовой долей соли 5 % пропустили избыток сероводорода. Вычислите массу осадка, образовавшегося в результате реакции.

В ответе запишите уравнение реакции, о которой идёт речь в условии задачи, и приведите все необходимые вычисления (указывайте единицы измерения искомых физических величин).

Общий план: 1) по массе, объёму или массовой доле раствора найдите массу или количество вещества исходного реагента (m(в-ва в растворе) = m(раствора) × w); 2) переведите в моли через Mr; 3) по уравнению реакции и его коэффициентам найдите количество вещества искомого продукта; 4) переведите в нужные единицы — массу через Mr, объём газа при н.у. через Vm = 22,4 л/моль. Проверьте, не дан ли один из реагентов в избытке.

Ход решения

Cu(NO3)2 + H2S = CuS↓ + 2HNO3

  1. m(Cu(NO3)2) = 37,6 · 5 / 100 = 1,88 г
  2. n(Cu(NO3)2) = 1,88 / 188 = 0,01 моль
  3. по уравнению n(CuS) = 0,01 моль
  4. m(CuS) = 0,01 · 96 = 0,96 г
