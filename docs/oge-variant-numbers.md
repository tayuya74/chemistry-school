# Номера случайных вариантов ОГЭ

Номер позволяет восстановить набор заданий на любом устройстве без базы данных,
аккаунтов и localStorage. Новый полный вариант имеет 9 символов, например
`2K7M4QP3D`. Алфавит не содержит похожих символов `0/O`, `1/I/L`. Регистр при
вводе не важен, пробелы и дефисы игнорируются. Для своего набора номер длиннее:
он дополнительно содержит количества выбранных типов.

Версия 2: первый символ — версия, следующие 6 символов кодируют случайное
зерно, следующий — режим, затем для своего набора идут тройки «тип +
количество», последний символ — контрольный знак от опечаток.

Старые номера версии 1 продолжают работать: первая цифра — версия, следующие 9 — случайное зерно,
следующая — режим (0 полный, 1 сложный полный, 2 свой, 3 сложный свой), далее для
своего набора пары «тип: 2 цифры, количество: 2 цифры», последние 2 — остаток
десятичного тела номера по модулю 97. Номер хранится и передаётся как строка.
Каталог сортируется по id, выбор без повторений — Mulberry32 + splice.

## Совместимость

- `data/oge/numbered-catalogs/1.json` неизменяем. Не пересоздавать его при сборке.
- Алгоритмы версий 1 и 2 в `js/oge-variant-number.js` неизменяемы.
- Новые задания включать через новую версию каталога и алгоритма, сохраняя
  поддержку всех прежних версий в поиске. Нельзя просто заменить каталог 1.
- Не удалять JSON и страницы примеров, на которые ссылаются выпущенные каталоги.
  Редактирование текста/ответа задания отображается и в прежних вариантах;
  закрепляются номера и порядок, а не историческая копия текста задания.
- При сбое загрузки показывать ошибку, а не подменять задание случайным.
- Совпавшие случайные номера обозначают один и тот же набор, не создают конфликт.
- Старые ссылки `#variant=...` и локальные сохранения продолжают открываться.
- Нумерация своих наборов версии 2 поддерживает до 999 примеров каждого типа;
  выбирается не больше доступного.

Проверки: `node scripts/test-oge-variant-number.mjs` и
`node scripts/test-oge-saved-variants.mjs`.
